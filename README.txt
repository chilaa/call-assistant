Call Clips

1. Unzip this folder and keep all its files together.
2. Open "Call Clips.exe".
3. If Windows shows a blue warning, click More info, then Run anyway.
4. To get a Desktop and Start menu icon: open Settings in the app and press
   "Add to Desktop and Start menu". Then you can also right-click the icon
   on the taskbar and choose "Pin to taskbar".

Clips are saved in Documents\Call Clips.

The app updates itself. To install it on another laptop, download the
newest version here:
https://github.com/chilaa/call-assistant/releases/latest/download/Call-Clips-Windows.zip
